# Contributing

Thank you for helping improve OOMU.

1. Read [LICENSE.md](LICENSE.md) and [DEVELOPMENT_SETUP.md](DEVELOPMENT_SETUP.md).
2. Keep changes focused and preserve OOMU's local-first permission and receipt boundaries.
3. Add translations in every locale whenever user-facing English text changes.
4. Never commit credentials, model weights, application state, test-account data, generated runtimes, or compiled binaries.
5. Run `npm run check:quality`, `npm run test:frontend`, and the relevant Rust tests before proposing a change.

Security issues should follow [SECURITY.md](SECURITY.md), not a public issue.
