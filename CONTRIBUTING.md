# Contributing

OOMU is maintained by Eldris, Inc. The canonical OOMU repository is changed only by maintainers expressly approved by Eldris.

## Public feedback

GitHub Issues are the public channel for:

- Reproducible defects
- Product feedback
- Feature requests
- Documentation corrections

Before opening an issue, search existing issues first. For defects, include the OOMU version, your operating-system version, clear reproduction steps, expected behavior, actual behavior, and any relevant sanitized logs or screenshots. Do not include credentials, API keys, personal data, model prompts containing confidential information, or other sensitive material.

Feature requests should describe the user problem and the outcome you need. Opening an issue does not create an obligation for Eldris to implement, prioritize, or respond to it.

## Code contributions

OOMU does not accept external code contributions. Pull requests are disabled, and unapproved patches, commits, branches, or forks will not be reviewed for inclusion in the canonical OOMU codebase.

Only maintainers expressly approved by Eldris may change the canonical repository. Eldris may solicit a contribution from a specific person under separate written terms; that invitation does not create a general contribution program.

## Security and legal matters

Report potential security vulnerabilities only as directed in [SECURITY.md](SECURITY.md). Do not disclose a vulnerability through a public GitHub Issue.
