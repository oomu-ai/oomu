# Security

Please report suspected vulnerabilities privately through this repository's GitHub Security Advisory page. Do not include credentials, private user data, or an exploitable proof of concept in a public issue.

Include the affected version, platform, impact, reproduction steps, and the smallest safe supporting evidence. OOMU maintainers will acknowledge the report, validate it against the real production path, and coordinate disclosure after a fix is available.

This repository never needs your model files, OAuth tokens, Apple credentials, keychain contents, or personal OOMU database.
