# OOMU 0.1.11 — Public Beta

OOMU 0.1.11 makes research requests more natural and presentation creation complete.

## What’s improved

- **Natural research requests reach the web.** Phrases such as “investigate,” “look for weak links,” and “find current opportunities” can invoke verified public research when the full request clearly needs current information.
- **Ordinary conversation stays ordinary.** Simple uses of words such as “look” or “investigate” do not trigger a search unless the surrounding request genuinely calls for public evidence.
- **Presentation requests create a real deck.** Asking OOMU to create a presentation on a topic now produces a verified PowerPoint file instead of stopping at an outline or asking for unnecessary clarification.
- **Your requested focus carries into the deck.** Details such as valuation risk, market hype, weak links, and investment scenarios remain part of the presentation brief.
- **Completion is receipt-backed.** OOMU reports success only after the native presentation artifact exists and passes structural verification.

## Security and data integrity

- Public research remains headless, bounded, and backed by native evidence receipts.
- Private information still requires OOMU’s explicit cloud-approval flow before it can leave the Mac.
- Presentation success requires a verified native artifact; a model’s outline or promise is not treated as completion.
- Existing Project boundaries, file permissions, and Auto-route controls remain unchanged.

## Install or upgrade

### Upgrading from OOMU 0.1.10

Choose **Help → Check for Updates…** in OOMU 0.1.10. You can also download `OOMU-0.1.11.dmg`, open it, and drag OOMU into Applications.

### New installation

Download `OOMU-0.1.11.dmg`, open it, and drag OOMU into Applications.

## Known limitations

- OOMU 0.1.11 is a public beta for Apple Silicon Macs running macOS 14 or later.
- Checking for and installing updates requires access to OOMU’s official GitHub Releases feed.
