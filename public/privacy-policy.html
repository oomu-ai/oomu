OOMU Privacy Policy

Last updated: July 10, 2026

OOMU is designed as a local-first desktop application. Chat transcripts, workflow state, local model files, user-selected files, and execution outputs remain on the user's Mac unless the user explicitly chooses an integration or action that sends data elsewhere.

Local Data

OOMU stores local app state, workflows, execution history, and identity material on the device. License acceptance is also stored locally on the device.

License Acceptance

OOMU Community License 1.2 requires explicit acceptance before licensed functionality becomes available. The accepted license version and acceptance time are stored locally. Accepting or declining the license does not send a request to OOMU or Eldris.

Web Grounding

When the user explicitly asks OOMU to search the web, or enables automated grounding for freshness-sensitive prompts, OOMU may query DuckDuckGo Lite directly from the user's Mac. This search path uses no OOMU search API key, cookies, browser automation, or Eldris proxy.

Cryptographic Identity

OOMU uses local Ed25519 identity keys to sign supported artifacts and records. Signatures provide proof of origin and integrity; they are not a mechanism for collecting user content.

User Controls

  • Users can turn automated web grounding on or off globally and per chat session.
  • Users can inspect and copy their public signing key.
  • Users control when workflows execute and when approval-gated actions proceed.

Contact

Privacy or licensing questions can be directed to Eldris, Inc. through the official support channel provided with the user's license materials.
